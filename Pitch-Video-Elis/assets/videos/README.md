# Opening clips

The two AI-generated cinematic clips used for the opening of the video. Origin and credits are in `../../ASSETS-AND-LICENSES.md`.

| File | Format | Used for |
|---|---|---|
| `01-incendio.mp4` | 1280×720, 24 fps, H.264 + AAC, 4.0 s | Opening, 0.0 to 4.0 s of the video |
| `02-transicion-elis.mp4` | 1920×1080, 24 fps, H.264 + AAC, 4.96 s | Transition, only its first 2.30 s are used |

These are the unmodified originals. The render uses the 1080p / 30 fps conversions in `video-remotion/public/media/`, which `npm run prepare:clips` can regenerate from these files.
