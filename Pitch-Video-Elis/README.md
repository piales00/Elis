# Pitch-Video-Elis

Production project for the **30-second ELIS pitch video** (NASA Space Apps 2026, challenge *Harmonization of MODIS and VIIRS Hot Spots*).

**ELIS** harmonizes fire detections from the MODIS and VIIRS satellites into one comparable record for Peru, measured in *fire cell-days* (grid cells of about 11 km with fire on a given day). It does not count individual fires or hectares. The application code lives in the rest of this repository (`api/`, `web/`, `docs/`, `scripts/`); this folder contains only the video.

The video is composed in code with **React + Remotion**: every frame is a pure function of one clock, so the same frame renders identically every time.

> **Status: preliminary visual version (v2).** The narration recording is not yet included, and subtitle timings are provisional. See [`video-remotion/NOTAS-PRODUCCION.md`](video-remotion/NOTAS-PRODUCCION.md).

## Quick start

Requires Node.js 18 or newer (developed with 22) and an internet connection on first run, when Remotion downloads its render browser.

```bash
cd Pitch-Video-Elis/video-remotion
npm ci                      # exact versions from package-lock.json
npm run dev                 # Remotion Studio preview
npm run render:v2           # asset check + render + audio trim -> out/elis-preview-v2-render.mp4
# optional: npm run prepare:clips regenerates public/media/clip01|02.mp4 from assets/videos/
```

Full instructions are in [`video-remotion/README.md`](video-remotion/README.md).
